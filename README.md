# Pemrograman Berbasis Objek

Repositori ini berisi materi, contoh kode, dan proyek terkait dengan Pemrograman Berbasis Objek (PBO). PBO adalah paradigma pemrograman yang menggunakan objek dan kelas sebagai dasar dari pengembangan software. Repositori ini dapat digunakan sebagai referensi belajar, tempat penyimpanan tugas, atau kumpulan modul pembelajaran.

## Pendahuluan

Pemrograman Berbasis Objek (PBO) memudahkan pengelolaan kode dengan memperkenalkan konsep seperti enkapsulasi, pewarisan, dan polimorfisme. PBO banyak digunakan pada bahasa pemrograman seperti Java, Python, C++, dan C#.

## Materi PBO

- Pengertian Objek dan Kelas
- Konstruktor dan Destructor
- Atribut dan Method
- Pewarisan (Inheritance)
- Enkapsulasi (Encapsulation)
- Polimorfisme (Polymorphism)
- Interface dan Abstract Class
